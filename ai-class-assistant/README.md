# AIクラス編成アシスタント

学校現場向けクラス替え支援アプリ。小学校・中学校・高校の3校種に対応し、クラス替え作業を大幅に効率化します。

## 特徴

- **完全オフライン動作** — 個人情報を外部に一切送信しない
- **文科省情報セキュリティガイドライン準拠**
- **3校種対応** — 小学校・中学校・高校のデータ形式を自動吸収
- **遺伝的アルゴリズムによる多目的最適化** — 上位5案を自動生成
- **ドラッグ&ドロップによる手動微調整** — リアルタイム統計更新
- **Excel入出力対応** — 既存名簿をそのまま利用可能

## 技術スタック

- **フロントエンド**: React 18 + TypeScript
- **スタイリング**: Tailwind CSS
- **Excel処理**: SheetJS (xlsx)
- **最適化エンジン**: 遺伝的アルゴリズム（JavaScript実装）

```bash
cd ai-class-assistant

```

## ビルド

```bash

```

## 4ステップワークフロー

1. **Step 0: 校種選択** — 小学校/中学校/高校を選択。プリセットが自動適用される
2. **Step 1: データ確認** — Excelから読み込み、または108名のサンプルデータで試用可能
3. **Step 2: 条件設定** — クラス数、NGペア/OKペア制約、最適化の優先度をスライダーで設定
4. **Step 3: 結果確認** — 上位5案をタブで比較。ドラッグ&ドロップで手動微調整。Excelで出力

## 正規化エンジン仕様

| 入力形式 | 対応校種 | 正規化方法 |
|---|---|---|
| 3段階（◎○△） | 小学校 | 100, 50, 0 に変換 |
| 5段階（1〜5） | 小・中・高 | 0〜100 に線形変換 |
| 100点満点 | 小・中 | そのまま0〜100 |
| 5教科合計（500点満点） | 中学校 | 500で割って×100 |
| 偏差値 | 高校 | (偏差値-25)/50×100 |
